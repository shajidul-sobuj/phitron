Problem 1: Hello, HSC!

Your first task is to print the exact string "Hello, HSC!" to the console.

No input is required for this problem.

Output Format:

A single line containing the string Hello, HSC!.

Hello, HSC!

Problem 2: Sum of Two Numbers

Read two integers from the standard input (stdin) and print their sum to the standard output (stdout).

Input Format:

A single line containing two space-separated integers, a and b.

Output Format:

A single line containing the sum of a and b.

Constraints:

0 <= a, b <= 1000

Sample Input:

5 10

Sample Output:

15

Problem 3: Leap Year Check

Given a year, determine if it is a leap year. A leap year is divisible by 4, except for years divisible by 100 unless they are also divisible by 400.

Input Format:

A single line containing one integer, year.

Output Format:

Print "Leap Year" if it is a leap year, otherwise print "Not a Leap Year".

Constraints:

1900 <= year <= 3000

Sample Input:

2000

Sample Output:

Leap Year
